# AI-Based Fake Identity & Document Screening System

An AI-powered document screening platform for border checkpoints that automates the analysis of identity and travel documents, detects tampering or forgery, validates data against rules and databases, and generates a risk score to help border security personnel make faster, more accurate decisions.

## Problem Statement

Manual document verification at border checkpoints is time-consuming, inconsistent across officers and checkpoints, and vulnerable to sophisticated forgery techniques that are difficult to detect with the naked eye.

## Solution

This project proposes an AI-driven platform that automatically:

1. Extracts data from identity/travel documents using OCR
2. Validates the extracted data against official document standards and databases
3. Detects signs of digital or physical tampering
4. Verifies that the document photo matches the presented individual
5. Generates a consolidated **risk score** to assist human decision-making
